# Support

- **Bugs and feature requests for an open source tool:** open an issue in that repository.
- **Questions about how to use a tool:** read the repository's README and `docs/` folder first, then open an issue.
- **Security problems:** see [SECURITY.md](SECURITY.md). Do not open a public issue.
- **Working with Growth Of Influence:** [book a call](https://growthofinfluence.com/book-a-call/) or visit [growthofinfluence.com](https://growthofinfluence.com).

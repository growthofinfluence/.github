# Contributing

Thank you for helping. These defaults apply to every Growth Of Influence repository that has no
`CONTRIBUTING.md` of its own.

1. **Open an issue first** for anything bigger than a typo, so we agree on the approach.
2. **Keep pull requests small.** One change, one pull request.
3. **Run the tests and the linter** the repository documents before you push.
4. **Never commit a secret**, a client name or personal data. Use made up examples.
5. **House style for prose:** no em dashes, plain words, American English.

By contributing you agree your work is released under the repository's license (MIT unless stated otherwise).
Please follow the [Code of Conduct](CODE_OF_CONDUCT.md).

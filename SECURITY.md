# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Email **chris@growthofinfluence.com** with:

- what you found and how to reproduce it (use made up data, never a real credential),
- the repository, version and your environment,
- whether you plan to disclose it, and when.

You will get an acknowledgement within five working days and a plan for a fix after that.
Credit is given in the changelog unless you prefer otherwise.

Each repository can add its own `SECURITY.md` with a narrower scope. It takes priority over this one.
